1. github.com pe free account banao, naya PUBLIC repo banao (jaise: job-feed).
2. Is zip ke saare files (hidden folder .github samet) repo mein upload karo.
3. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. Actions tab > "update-jobs" > Run workflow. 1-2 minute baad jobs.json bhar jaegi.
5. Site ka link: https://<tumhara-username>.github.io/job-feed/
Uske baad ye har 6 ghante mein apne aap update hoti rahegi.
